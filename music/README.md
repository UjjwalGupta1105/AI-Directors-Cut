# Background Music

Place a royalty-free MP3 file here to enable background music in your highlight reels.

The application looks for any `.mp3`, `.wav`, or `.ogg` file in this directory.

If no file is found, the app works perfectly without music.

## Royalty-Free Music Sources

- https://pixabay.com/music/ (free, no attribution required)
- https://freemusicarchive.org/ (various licenses)
- https://www.bensound.com/ (free with attribution)

## Mixing

When music is enabled:
- Volume: 7% (very subtle)
- Ducked further under narration and video audio
- Loops automatically if shorter than the video

## Example

```
music/
└── ambient_background.mp3
```
